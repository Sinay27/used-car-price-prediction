# Dissertation
 
In the main branch, the visitor will find 9 files ( including this file ).
Datasets:
Cars.csv which is the original dataset.
Validation.csv is the dataset used to validate the models.

Models : 
In this branch, there are 3 doubled models ( V: for validation; O: for original ).
Linear_regression_model(O).ipynb.
Linear_regression_model(V).ipynb.
KNN_model(O).ipynb.
KNN_model(V).ipynb.
XGB_model(O).ipynb.
XGB_model(V).ipynb.

To run any script of these 6 scripts, the user has to :
- Install to make sure that Python and necessary packages are imported.
- Draged the correct (V/O) dataset into the Google Colab files tab.
- Wait until all cells are executed.
